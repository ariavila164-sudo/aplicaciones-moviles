# Sabor Casero (Flutter)

Uso:
1. Descomprime y entra a la carpeta.
2. Si no existen las carpetas de plataforma: `flutter create .` (no sobrescribe lib/ ni pubspec.yaml).
3. `flutter pub get`
4. `flutter run`

Android: asegúrate de que android/app/src/main/AndroidManifest.xml tenga
<uses-permission android:name="android.permission.INTERNET"/> (para cargar imágenes).
